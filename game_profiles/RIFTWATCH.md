# 既有遊戲專案 Profile — 世紀帝國二：裂境守望

此文件僅是已知專案脈絡摘要，**不是**完整 v3.0 企劃書；真正的功能驗收仍以使用者提供的 v3.0 原文及既有 repo 程式碼為準。

- 繁中：世紀帝國二：裂境守望
- 英文：Age of Empires II: Riftwatch
- 日文：エイジ オブ エンパイア II：裂境の守り
- 類型：原創桌面 RTS / Roguelite，受 AoE II 啟發；需保護原創素材及遊戲資產權利。
- 既有技術：原型為 **純 HTML / CSS / JavaScript ES Modules，沒有建置步驟**。
- 已知需保護的既有能力：四語系、Nemesis Director、10 波流程、近期截圖與可玩原型。
- v3.0 企劃中的已知方向：16 文明、8 生態環境、32 張卡牌、10 波、160 事件實例、四語系、GM 編輯及效能驗證。
- 目標單局長度：25–35 分鐘；曾有四種可選控制模式規劃。

## 嚴格工程規則
1. 永遠先在既有 repo 測試，不得擅自遷移 Godot/Unity/React 或重構所有系統。
2. 啟動 Dev Server 後建立基線截圖，記錄畫面、操作、console errors、關卡流程。
3. 必須建立可讀取 v3.0 企劃分片的索引，當任務涉及需求時只載入對應章節。
4. Agent 輸入單次不超過約 6,000 中文字元；啟動檔約 2,700 字元以下。
5. 修改遊戲時保留四語系、Nemesis Director、10 波及可玩性；新增功能不得刪除既有內容。
6. 每次提交有 Git commit、測試證據與可還原點。

## 初始驗收
能在本地以 Vite 啟動目前 HTML 原型並正常使用 ES Modules；能修改單一檔案即時預覽；能在 PR review 前跑自動化回歸測試。
